# Factory library overhaul, 2026-10-23

Base: `main` after PR #328 (`dbf563e`). Working tree had unrelated local edits; they were not committed.

| Protected (Mesa High Gain) | 1 | 1, hash unchanged |

| Newly developed | 0 | 10 |

| Native FactoryUseCase / loudness this pass | not run here | contracts added, binary not rebuilt |

No guitar preset was removed. Crunch, clean and metal clusters keep distinct block signatures. Correlation was not used as a delete rule.

## Metadata

Every preset except Mesa High Gain now stores `soundSources`, `processingTypes`, `style`, `role`, `requiredInputs`. Mesa stays byte-identical. Missing fields fall back from `category` so user presets still filter.

Vocoder inference no longer tags `sidechain`.

## Explorer

Source, type and style are independent filters. Multi-select within a dimension, AND across dimensions. Search is unchanged. Factory/user, favourites, load/save and keyboard movement stay.
