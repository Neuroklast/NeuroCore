# C08 initial MSEG model

The engine has no editable multi-segment control source. A bounded 2–64 point curve owns normalized times, bipolar levels and a power curve for each outgoing segment; playback advances one normalized phase with optional point-index loop bounds and sustain, while gate release completes the remaining segments. Portable numerical contracts establish interpolation, invalid-data rejection, loop/sustain/retrigger and bounded extreme increments before the source is integrated into the shared control graph; native contracts cover timebase, MIDI, restore and buffer independence.

Points use `time:value:curve` separated by commas, starting at time 0 and ending at 1 with strictly increasing times. Values are −1…1, curves −8…8; zero is linear and positive values delay the rise (`t^(2^curve)`). Duration is seconds unless sync is a note division; full-cycle duration is then `240 / BPM * numerator / denominator`. Free source starts on prepare/reset; MIDI/audio sources start on a rising gate. One-shot holds the final point. Loop mode wraps between point indices while free or gated; sustain takes precedence over looping. On gate release sustain/loop stop and the remaining curve plays to the final point. Gate retrigger on restarts at zero; off waits until playback has ended. Gate input uses audio channel 0 > 0.5 or cached MIDI gate. The curve is immutable during playback, with no heap operations.
