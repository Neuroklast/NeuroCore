NEUROKORE 0.6.4-beta alpha test build. See the attached platform archives and
SHA-256 checksums. Each archive contains the native plugin, standalone app,
license text, EULA, alpha tester agreement, installation notes and build ID.

Windows: x86_64 VST3. Linux: x86_64 VST3. macOS: universal Intel/Apple Silicon
VST3 and AU. These are alpha binaries, not a certification of every DAW.
Windows builds are unsigned; macOS builds are ad-hoc signed, not notarised.
Personal activation licenses are supplied separately by NEUROKLAST.

The workflow publishes this release only after all three native builds,
the full native test suite and the web test suite succeed. See the source
commit and its Actions run for validation evidence and known limitations.
