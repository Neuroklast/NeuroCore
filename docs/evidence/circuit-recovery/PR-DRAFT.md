# Restore NEUROKORE's dotted IC chip identity

Circuit chips again show complete effect names, separate typecodes/controls, cut-corner frames and a dotted signal surface. Calculated NodeFaces remain as subdued overlays that strengthen on focus. Full parameter captions and macro endpoints have their own band above the node ID/live level, using the same snapped geometry as the edge contacts. Connected pins light from source telemetry; idle pins remain metal. Parameter ports now accept modulation and reject audio in the headless board.

No DSP, version, camera-controller or source-editor changes. Historical code was used to reconstruct the visual chrome rather than restore old BoardChip implementations.

Screenshots and full provenance: `docs/evidence/circuit-recovery/README.md`.

Validation: production build/TypeScript passed. Browser runs: 12 passed total, 2 existing density variants skipped. Assembly/theme suite: 468 passed and 4 pre-existing failures, independently reproduced on main. DOM collision, clipping, resize, zoom, four themes, three presets, context-menu camera lock, Source Inspector and real-pointer modulation magnet tests are covered.
