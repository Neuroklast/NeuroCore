# NEUROKORE

NEUROKORE ist ein Insert- oder Send-Effekt von Neuroklast. Lade einen Factory-Sound, drehe die Regler a–f, oder schreibe eine kurze Formel (Drive, Filter, Delay, Reverb, Kompressor, Gate, Limiter, IR-Cab, Crossover, Envelope, Oszillator).

Die Oberfläche ist auf Englisch. Dieses Dokument ist die deutsche Bedienhilfe.

30-Sekunden-Weg
1. Presets öffnen und eine Factory-Zeile doppelklicken (Amp, Delay, Reverb, Vocal).
2. Audio spielen. Mix anheben, bis der Effekt hörbar ist.
3. Regler a–f drehen. Namen und Bereiche kommen aus der Formel.
4. Eigenen Sound? Edit, Formel ändern, Save.

---

## 1. Schnellstart

NEUROKORE auf eine Spur oder einen Send legen. macOS: AU und VST3. Windows/Linux: VST3 oder Standalone.

Preset laden
- Presets in der oberen Leiste.
- Scope auf All oder Factory lassen.
- Zeile doppelklicken oder Load.
- Der Chip neben Presets zeigt den Namen. < und > blättern durch die Bibliothek.
- Passt das geladene Skript zu einem Factory-Preset, erscheint dieser Name.

Hören
- Mix 0 % ist trocken.
- Insert: etwa 40–70 %. Send: Mix hoch, Pegel über den Host-Send.
- L / BOTH / R wählt, welchen Eingangskanal die Formel hört. BOTH ist Standard. L oder R kopiert diese Seite auf beide Kanäle.

Sound ändern
- a–f lassen sich vom Host automatisieren.
- Tut ein Regler nichts, kommt der Buchstabe in der Formel nicht vor.

Formel
- Edit öffnet den Texteditor. Vorschläge erst mit Ctrl+Leertaste (Mac: Cmd+Leertaste).
- Save wendet die Formel an. Eine rote Zeile erklärt Fehler.
- Copy legt die Formel in die Zwischenablage.

Eigenes speichern
- Presets → Save As…
- Name, Author, Category.

## 2. Oberfläche

Obere Leiste
- NK + NEUROKORE: Marke. Klick öffnet neuroklast.net.
- Presets: Factory und eigene Sounds.
- Name-Chip: geladenes Preset oder Untitled. < / > blättert.
- Functions: Wörterbuch. Ordner: Core, Drive, Crush, Blocks.
- Stages: Blöcke der aktuellen Formel und welche Regler sie nutzen.
- Settings: Animation Full / Reduced / Off, Studio / Live, UI-Scale, Formelgröße, Standalone-Audio.
- LIVE / STUDIO: Live = min-phase Oversampling (kaum Latenz). Studio = linear-phase.
- Bypass: Mix auf 0, Slider gesperrt.
- License: signierte .lic importieren. Danach zeigt License den Inhaber.
- Help: diese Anleitung (englische In-Plugin-Hilfe).

Regler
- Sechs Knöpfe in einer Spalte: a, b, c, d, e, f.
- Name über dem Knopf umbenennen schreibt `param a = …` ins Skript.
- Der aktuelle Wert steht unter dem Zeiger, nicht in der Mitte der Scheibe.
- Rechtsklick: MIDI Learn.

Formelbereich
- L / Both / R: gleiche Breite wie die Knöpfe, gleiche Zeile wie Circuit / Terminal.
- Circuit / Terminal: zwei Sichten desselben Konstrukts.

Circuit = zusammenbauen
- Die Fläche ist eine Platine: dezente rose Kreuze zur Orientierung.
- Blöcke rasten auf 16 px ein und sehen aus wie Chips (Fase, Kerbe, Pin-1, DIP-Pads).
- Ziehen ändert nur X/Y, nicht die Signalreihenfolge. Reihenfolge im Overlay oder per Kabel.
- Rechtsklick: Auto-arrange, oder Modul hinzufügen (Kategorien). Factory-Presets kommen schon angeordnet zur aktuellen Zoom-Stufe.
- Mid-Side Encode teilt MID- und SIDE-Schienen wie ein Bus. Decode führt sie zusammen. Widen ist Breite, nicht MS.
- Kabel ziehen: die Zielbuchse leuchtet, sobald du loslassen kannst. Leitungen laufen orthogonal wie Leiterbahnen (runde Ecken, parallele Bus-Lanes); Punkte nur bei Signal.
- Ctrl+Mausrad zoomt.
- Doppelklick: Overlay für alle Parameter. Gebundene Knobs stehen rot auf dem Chip.

Terminal = hacken
- Dieselbe Kette als Text.
- Live-Ansicht: farbige Regler und aktuelle Werte in Klammern (`a[3.20]`).
- Edit öffnet den Editor, Save wendet an.
- IR-Button sitzt in der Zeile, nicht darunter.
- Positionen stehen als Kommentar `# @x,y` und ändern den Klang nicht.

IR
- Jede `ir1` / `ir2`-Zeile hat einen Button in Zeilenhöhe. Drop, Load, Clear.
- Amp-Factory-Presets kommen mit Cabinet. Slot leer = trocken.

Unten
- Tools-Zeile (zwischen Editor und Scopes): Oversampling, Polisher, Mix. Mix-Glitch nur im Slider.
- Fußzeile: NKOS LIVE / STUDIO / BYPASS / SAFE, CPU, Latenz, SR, 32f, BUF, BPM HOST oder USER, OS.
- IN / OUT: Welle, Stereofeld, Loudness.

## 3. Regler a–f

```
param a = Drive [0.5, 6.0]
param b = Tone [800, 9000]
param c = Time [1/1, 1/16]
stage1: y = softclip(x, a)
filter1: type = lowpass; cutoff = b; resonance = 0.3
delay1: time = c
```

- Der Host sieht jeden Regler als 0–1.
- `param a = Name [min, max]` mappt auf den geschriebenen Bereich.
- `param c = Time [1/1, 1/16]` rastet auf Notenwerte. In der Formel ist c Millisekunden beim gewählten Tempo (Settings: Host oder User).
- Settings → Tempo: Host folgt der DAW. User = eigene BPM. Die Fußzeile zeigt HOST oder USER.
- Circuit: Ctrl+Mausrad zoomt. Leitungen weiss/grau, Punkte folgen dem Input. Gebundene Knobs stehen rot auf dem Chip.
- `ngate1: threshold = -48` ist ein Noise Gate. attack und release sind optional.
- Ein alleinstehendes `e` ist Regler e, nicht 2.718. Dafür `exp(1)`.

## 4. Sprache (Kurz)

| Block | Aufgabe |
|-------|---------|
| `param a = Name [min, max]` | Regler a und Bereich |
| `stageN: y = …` | Sample-Mathe (`x` rein, `y` raus) |
| `filterN: type = lowpass; cutoff = …` | SVF low / high / band |
| `delayN: time = …; feedback = …; mix = …` | Delay, samplegenau, auch bei 8× ohne periodische Ticks |
| `reverbN: size = …; decay = …; mix = …` | Hall |
| `compN` / `gateN` / `ngateN` / `limitN` | Dynamik |
| `msN: mode = encode` / `decode` | Mid/Side aufteilen / zusammenführen |
| `widenN: width = …` | Stereobreite (kein MS) |
| `xoverN: f1 = …; f2 = …` | Bänder |
| `bus name:` + `send:` + `out:` | parallele Schienen |
| `irN: mix = …` | Impuls (Pfad steht nicht in der Formel) |
| `oscN` / `envN` | LFO / Hüllkurve |

Volle Referenz: docs/DSL_REFERENCE.md

## 5. Lizenz

Ohne Lizenz: 20-Minuten-Demo, danach Mix = 0 (trocken). Die Formel bleibt geladen.
License → .lic wählen. Datei liegt unter AppData (NEUROKLAST / NeuroKore).
